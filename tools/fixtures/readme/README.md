# README 截图的源码快照

`stm32f103_scope/main.c` 与 `stm32f103_regs.h` 保留提交 `8c317ad` 的源码内容，配合该提交已入库的 [`stm32f103_scope.elf`](../dwarf/stm32f103_scope.elf)。当前目标例程已继续演进，不能把新源码直接配给这份历史 ELF，否则行号会错位。

这份快照仅用于 README 的模拟调试场景，不替换当前目标例程，也不用于烧录。截图脚本为 [`capture-readme-pages.mjs`](../../dev/capture-readme-pages.mjs)。
