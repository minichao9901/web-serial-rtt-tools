# 示例素材：屏页「动画 / 视频」

给 `#panel`（SPI/QSPI 屏页）的「动画 / 视频」用的测试素材：**每个文件都对应一个"看什么"**，
所以屏上出了问题时能一眼归因，而不是盯着一团会动的东西猜。

用法：屏页 → 「动画 / 视频」→ **选择文件…** → 选下面任意一个 → **播放到屏**（先连上探针/假探针）。
尺寸按真屏生成（AXS15352 = 240×296、ST77916 = 360×360），页面里的「铺满 / 适应」会自行缩放。

| 文件 | 格式 | 看什么 |
|---|---|---|
| `bars-sweep-240x296.gif` | GIF · 50 帧 | **彩条 + 横扫白线**：颜色顺序对不对（R/B 交换了立刻能看出）、底部 11 级灰阶能不能数清、白线直不直（撕裂/整列错位） |
| `ball-grid-240x296.gif` | GIF · 60 帧 | **网格 + 弹跳球**（带拖尾）：运动均匀不均匀 —— 丢帧时球会"跳格"，撕裂时圆边断开 |
| `rgb-ramp-240x296.webp` | 动画 WebP · 36 帧（无损） | **色相/明度平移** + 底部 16 级灰阶：RGB565 的色深够不够（台阶、发绿）、字节序对不对 |
| `count-cube-240x296.apng` | APNG · 50 帧（无损） | **帧号 + 秒针 + 旋转立方体**：帧号连续 = 不丢帧，秒针一格 = 25 帧；APNG 走 ImageDecoder 那条路 |
| `checker-scroll-360x360.webm` | WebM/VP9 · 3 s | **棋盘斜移 + 红边框 + 蓝十字**：撕裂/卷屏（棋盘最敏感）、四边边框都在不在（开窗算错会缺边）、十字是否居中 |
| `cube-clock-360x360.mp4` | MP4/H.264 · 4 s | **旋转立方体 + 秒针 + 帧号**：流畅度的天花板（AXS15352 实测 ~20 fps、ST77916 ~13 fps）、H.264 解码通路 |

两条口径上的坑，看数据前先知道：

1. **GIF 是按链路速度播的，不按文件里写的帧时长**（设计如此：发送才是节拍器，解码更快就丢帧）。
   所以一个 2 秒的 GIF 在假探针上可能 0.7 秒就播完了。**要判断"作者定义的时长/流畅度"，用 MP4 / WebM**——
   视频那条路走 `<video>` + `requestVideoFrameCallback`，是按真实时间播的。
2. **一帧就是一整屏**（240×296 = 142 KB/帧，360×360 = 253 KB/帧）。链路实测 ~3 MB/s，
   所以 ~20 fps 就是 AXS15352 的上限；帧率上不去先看是不是**链路**喂不满，别先怀疑素材。

局部刷新适合静止背景上的小范围运动（如 `ball-grid-240x296.gif`），当前算法发送所有变化像素的一个包围矩形；超过整屏 60% 就整帧发送。`花园.mp4` 为 568×320、30 fps，自然场景变化分散，360×360 铺满测试中每次变化包围盒均覆盖整屏，像素节省为 0%；开关局部刷新不会明显提速。历史 GIF 高帧率数据不代表普通 MP4 视频也能达到同样帧率。[具体分析](../../docs/validation/2026-10-10-garden-partial-refresh.md)。

## 重新生成

```powershell
make samples-anim                              # = python tools/dev/make-anim-samples.py
python tools/dev/make-anim-samples.py --out D:\some\dir
```

依赖：`pillow`（画帧，顺带用系统里的 msyh.ttc 烧中文说明）+ `numpy` + `imageio-ffmpeg`
（自带 ffmpeg 7.1，编 H.264 / VP9；不需要系统装 ffmpeg）。生成脚本在 `tools/dev/make-anim-samples.py`，
每个素材的"看什么"都写在函数注释里 —— **改图案时连带改这张表**。

生成是**可复现**的（连跑两遍字节一致，不需要 `git add` 刷一遍）：Pillow 那三条天生确定；
视频那两条加了 `-fflags/-flags +bitexact`（matroska 默认会写 DateUTC 之类的元数据，
不然每次重造 WebM 都会"看起来被改过"）并在 VP9 上钉了 `-threads 1`。

素材合计 ~1.2 MB，随仓库一起走（不进 GitHub Pages：部署只拷 `index.html app docs`，
线上页面从本地磁盘选文件即可，页面不需要能 fetch 它们）。
