# USB 示波器 / DAC 预留（待板测）

入口 `index.html#analog`。页面以 ADC 示波器和 DAC 信号发生器两个独立子标签组织，连接/断开状态栏常驻；HID 控制保持 64-byte 报告、4 ms 轮询。
ADC 数据复用 SPI/QSPI 的 WebUSB IN 0x8B；两者互斥，不新增端点。
首次采集需授权与 HID 同一台探针的 WebUSB。

## ADC

- 当前高速模式为 HPM5301 EVKLite PB14 / ADC0.6，J3[10]，与 QSPI IO2 共脚。
  输入限于 0–VREFH，必须共地并断开外部 QSPI 驱动，宜使用低阻源。
  无 SPI bridge 且 VREF/LED 共用 ADC 的 akaLinkPro 板型明确返回不支持此模式。
- GPTMR1 通道 2 经 TRGM 硬件触发 ADC 自带 DMA，无逐样本中断。
  8/10/12/16-bit 为硬件转换分辨率；请求整数速率 1–2,000,000 Sa/s。
  以返回的实际定时器速率建立横轴。最高请求速率、持续 USB 吞吐和有效精度待板测。
- 固件复用 SPI OUT 16 KiB DMA 环形缓冲和 IN 8 KiB 双发送块；慢主机时停止并报溢出，
  不静默覆盖。ADC 占用时固件拒绝 SPI、周期任务和 RTT/JScope 新启动。
- 单次按钮采集一个设定时窗，点数限制 32–65536；可设置有限记录或 0=连续。
  示波器提供时间/电压刻度、垂直偏移、自动/正常触发、上升/下降沿、触发电平和显示冻结。
  触发为网页软件触发，约 25% 预触发；单次按钮是有限 DMA 记录，不是硬件触发捕获。
- 固定 Uint16 环形历史保留最近 65536 点。绘图按像素保留最小/最大值，避免抹掉窄脉冲。
  记录不足时仅绘制实际时长，不拉伸改变横轴；正常触发未找到交越时保持上一帧。
  CSV 导出保留历史，时间以实际采样率换算；这不是无限长完整记录文件。
- USB 解析与绘图分开，单个挂起 IN 读取，逐块处理，不创建逐样本对象。
  停止等待 END、CLOSE 与硬件清理；失败保留占用供重试。冻结仅停止显示，采集仍运行。

### 游标与自动测量

波形区顶部合并电压读数与游标工具，下方六项自动测量采用单行读数条。游标输入仅在启用对应轴时显示；操作说明与测量状态在左栏「游标与测量说明」中展开，周期/频率的悬停提示也会说明无法测量的原因。窄屏时读数自然换行。

ADC 波形上方可分别开启时间游标 T1/T2、电压游标 V1/V2。拖动对应颜色的线，或在“点图移动”选择游标后点击波形；下方数值框可精确输入时间（µs）和电压（V）。点击波形后可用方向键微调，Shift 加快；时间方向每步为实际采样间隔。复位游标将已开启的两对线放到窗口内，清游标关闭两组。

- 时间以当前显示窗口左端为 0，显示 `Δt = T2 − T1` 和 `1 / |Δt|`；重合时频率显示 `—`。它是用户所选间隔的倒数，需自行让两条线对应完整周期。
- 电压显示 `ΔV = V2 − V1`。两类差值保留正负号，游标交叉时不自动交换。改变时基/垂直中心不会悄悄更改游标的时间/电压值；移出窗口后可按复位重新定位。
- 冻结、停止后仍可操作游标，并调整显示刻度。冻结保留原始帧，新 USB 数据仍入历史；不会用后台的新数据替换已冻结帧的测量结果。正常触发未命中时，波形与自动测量一起保持上一帧。

波形下方持续显示当前窗口的周期、频率、Ymin、Ymax、Yavg、Ypp。电压统计使用原始码值、该帧位宽和参考电压换算；Ypp 为最大值减最小值，不用像素包络或抽点估计。记录不够一屏时只测已有样本；缩小时间范围时只测实际显示的样本。

周期/频率估算使用 50% 幅度的同向交越、15% 幅度回差、线性插值、交越间隔一致性和一周期延迟相关性。需要至少三个同向交越（两个完整周期），每周期至少四个样本；幅度小于 8 LSB 或满量程 0.1%、直流、周期不足、周期不稳定或波形不重复时显示 `—` 并注明原因。估算依赖采样数据，不能消除混叠，也不替代 ADC 时钟与电压的外部校准。

计算、冻结视图与既有 ADC/DAC 回归：`make test-analog`。真实 DOM、四种游标绘制、鼠标拖动、精确输入、键盘、冻结/缩放、保持触发帧和窄屏布局：`make test-adc-measure-page`，使用已知 1 kHz / 2 Vpp 原始样本，不连接硬件。需先启动本地服务和 CDP 浏览器；可用完整 URL 的 `CDP` 环境变量（如 `http://127.0.0.1:9334`）指定独立测试浏览器，避免影响正在调试的会话。运行会切换该测试浏览器的页面。验收截图可通过 `ARGS=--screenshot=tmp/adc-measure-preview.png` 保存。

## 协议和生命周期

0x38 action 9 查询 ADB2：EP=0x8B、版本 2、位宽掩码、通道、最大速率、DMA/块大小、
占用 flags、支持标志、参考电压。action 10 OPEN 携带位宽/速率/点数；
13 START，11 END，12 CLOSE，14 STATUS。OPEN 不启动采集，先挂起读取再 START。

启动前由共享资源协调器释放 SPI/周期/目标引擎。CAPS bit1 忙则拒绝；
只有 bit1=0 且 bit0 表示旧 SPI OUT 仍挂起时，才发 OUT 0x0B 零长度包使其完成。
固件确认端点和缓冲空闲才授予 ADC。OPEN 应答丢失时用 STATUS 恢复任务代数并结束。

ADS2 为 32-byte 头加最多 2031 个 u16 码值：版本/type/bits/flags、token、块序号、
首样本索引、实际速率、数量、通道、stride、fault。最大 4094-byte 短包。
网页校验长度、码值范围、连续块序号/索引和任务代数；解析错误后仍尝试停止并排空 END。
END 传输完成且硬件恢复之后才释放资源，不用整机 USB reset 取消读取。
原 HID 低速 ADC 和 SPI/I²C 周期协议保留供旧客户端使用；新示波器不经过周期结果队列。

## DAC

页面为信号发生器界面，物理输出仍为未来硬件预留。内置正弦、方波、三角、
上/下锯齿、脉冲、直流和循环伪随机噪声，支持离线预览/CSV。
频率、初相位、脉冲占空比、更新率可调；最大/最小电压、峰值幅度 Vp、峰峰值 Vpp、
共模/offset 双向联动。Vmax=Vcm+Vp、Vmin=Vcm−Vp、Vpp=2Vp；
直流只使用共模电平，幅度/频率等无效控件禁用。超出 0–满量程时拒绝生成，不自动削顶。

预览、CSV 和上传共用完整一周期 LUT，点数 round(更新率/频率)，最少 8 点；
界面显示点数量化后的频率、表时长和点数。噪声表按指定点数重复，非无限随机流。
修改设置仅改变待输出表，运行中的波形需先 OFF 再 ON；不会自动重配置硬件。
0x38 的 DAC 能力/上传/启动/停止/状态协议已保留，
当前 HPM5301 固件宣告 0 通道，输出按钮禁用；不会启动 DAC 定时器或 DMA。
未来驱动广告能力后界面按能力启用，详见 [usb-analog-dac-hid.md](usb-analog-dac-hid.md)。

未来 probe 驱动采用定时器硬件触发 → DMA 循环读取 LUT → DAC 更新。
网页一次上传波形表再 START，不依赖操作系统定时器逐点发送；
驱动在 CONFIG/START 返回量化后的实际更新率，网页据此报告实际输出频率。
此轮仅修改 Web 界面和波形模型，没有实现或启动 DAC 硬件驱动。

## 复审后的模块边界与恢复规则

- model：纯波形/电平/LUT 数学；adc-protocol / dac-protocol：协议与能力校验。
- transport：共享 USB lease、单个原生请求、严格块解码；session：任务生命周期与统一资源管理。
- scope-store：固定容量历史和软件触发；view：控件/绘图，不直接收发硬件。
- ADC/DAC 使用统一 analog 会话，并登记已有 spi-bulk 等资源，没有第二套协调器。子标签只切换视图，不断开设备、不重建会话。
- `make test-offline` 内的浏览器 UI 自测会验证点击与方向键切换、ARIA 选中状态、隐藏面板和共享会话连续性。
- 连接在异步授权/能力查询后检查取消；HID 关闭失败保留句柄和管理器故障供断开重试。
- 原生 SPI OUT 未完成时保留占用，禁止重复退场；ADC STOP 不释放 DAC 任务。
- DAC BEGIN 应答丢失通过 STATUS 恢复，失败保留占用；缺少 ADC 能力不会禁用可用 DAC。

已覆盖上述异常路径及 ADC 最早可用触发边界的主机回归。2026-10-06 的真实浏览器/探针 ADC
矩阵也已通过：293 项通过 / 0 失败，覆盖 4 种位宽、6 档有限采样率、DMA 环回及持续采集，
结果见[硬件测试记录](validation/2026-10-05-hardware-test-results.md)及本地原始报告
`tmp/adc-hw-stress-2026-10-06.json`。未接校准信号源，因此不对 ADC 线性度、ENOB 或绝对电压精度作结论；
ADC 活动期间 RTT/JScope 本来就被资源所有权拒绝，关闭 ADC 后的吞吐对比仍需单独测量。未来 DAC 驱动尚未实现。

## 接线图

ADC 连接区提供“引脚分配图 / 接线”。与 I²C 页共用只读弹窗组件，
三页与 SPI 共用 board-pinout 的 J3 针号数据，不复制硬件表。
当前协议不提供板卡 ID，需手动确认 HPM5301EVKLite；未知板型不显示固定图，
连接变化后清除旧选择。已连接固件无 ADC DMA 能力时，不展示可用 ADC 接线。
ADC 高亮 J3[10]/PB14/ADC0.6 和全部 GND，说明 0–VREFH、参考校准与输入范围的区别、
QSPI IO2 共脚及高速低阻源要求。弹窗仅显示资料，不发送命令或占用采集资源。
