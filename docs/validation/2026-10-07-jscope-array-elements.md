## 使用方法

刷新网页，在 JScope 中载入 ELF，使用新增的“数组元素”输入框和“添加元素”按钮，也可以按 Enter：

- `gnetif.hwaddr[0]`：添加并勾选一个标量元素。
- `_SEGGER_RTT.aUp[0].WrOff`：添加结构体数组中的指定成员。
- `_SEGGER_RTT.aUp[0]`：把这一元素的四个可采标量成员加入列表，再选择需要的成员。
- `rx_buff[1][10]`：多维数组按每一维的下标定位。

输入框有 RAM 数组候选提示。按 ELF/DWARF 的类型、元素大小和成员偏移计算地址；不接受任意运算或指针跟踪。越界、长度未知、位域、不支持的布局及非 RAM 地址会给出错误。结构体元素中的指针、位域和嵌套数组不自动展开；嵌套数组可指定完整下标后单独添加。

不会把整个大数组展开成数百万条列表。数组按目录记录，仅解析用户要求的元素。一次结构体展开最多 256 个标量，超过时要求指定具体成员。最多同时采样 8 项，探针协议和数据解码保持原实现。

列表文案改为“直接列出”“数组”“未直接列出”，避免把尚未按下标添加的数组误称为完全不可采。
