# SWO 简化 C 导出

2026-10-10。将 SWO 分析页的“完整导出 .txt”按钮替换为“导出简化.c”，保存为 `swo-simplified.c`；完整 `.c` 导出保留原有功能。

简化输出不包含事件、时间、PC、路径、统计等生成注释；移除源码注释，保留字符串与字符字面量内容。仅写出采样对应的 C/C++ 源码行，不补齐未观测代码。

按原顺序合并连续重复源码位置及连续重复的短代码片段。重复检测窗口最多保留 128 行，支持最多 64 行的重复片段，不需要缓存整个导出文件。`A → B → A` 保留，不同文件或行号的相同代码不混合；溢出、传输缺口或无法定位的样本切断合并，输出用空行分开。

简化导出要求匹配 ELF 和源码，无可导出源码时明确拒绝；部分无法定位的 PC 被跳过并在页面提示数量。Worker 仍逐块写文件、等待写入确认，不受页面筛选区间及 250000 条事件展开上限影响。旧 `.txt` 接口供历史测试和脚本使用，页面不再提供按钮。

后台模块采用版本化加载，先安装消息接收再等待导出模块，避免初始准备消息在异步启动期间丢失。

## 验证

- 连续重复行、重复多行块、非连续返回顺序、跨缺口不合并、不同源码位置、流式窗口边界及大重复输入均通过。
- 多行注释、行尾注释、字面量中的 URL / 注释字符及 C++ 原始字符串均正确处理。
- 原完整导出仍覆盖 260000 个事件，不受 UI 上限截断。
- 入库 F103CB 实测 B 分支：**8432 PC → 3411 源码行**，合并 5021 条重复行，无源码跳过；完整文本 1,979,602 字符，简化为 **116,944 字符**，减少约 **94.1%**。
- 源码版 SWO 真页面 **44 项通过**，验证真实按钮、`.c` 文件名、Worker 输出、纯源码内容及原完整导出；合并版同一导出流程通过。
- 本轮为离线记录与页面测试，未连接或操作目标板。

复测：`node tools/selftest/swo-export.test.mjs`；使用本地页面和 CDP 测试浏览器运行 `node tools/selftest/swo-page.test.mjs`。合并版可将 `APP` 设置为带 `?modules=bundle&` 的页面地址。
