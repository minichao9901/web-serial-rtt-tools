# SPI/QSPI 屏刷屏区域布局修正

原“刷这一张”按钮位于预览右侧参数列底部。1500×800 窗口下被 `.imginfo` 的内部滚动区遮挡；1280×720 和 960×640 下还超出刷屏页可视范围，造成按钮像是消失。

最终布局保留“刷屏 / 面板初始化 / 读回”三个页签。刷图、图片设置、动画播放都在同一个刷屏页签中：顶部两组图案（纯色、图案）及选择图片/刷这一张操作栏，中间左侧大预览、右侧两列紧凑参数，底部一行动画播放操作。文件入口不再单独占一行，支持将 BMP/PNG/JPEG 拖入预览区。预览窗口与分片说明默认折叠。自定义宽高只在选择“自定义”时显示，套用内置屏推荐值时同步隐藏。压缩主区与日志之间的间距，默认日志高度 110 像素，仍可拖动调整。视频解码元素不可见；载入图片、视频或动图后直接更新主预览，视频/动图首帧预览不发送数据，按屏幕窗口缩放。动画播放仍使用该主预览。

预览画布占满分配的区域，按原图比例显示；移除旧的 380 像素宽度上限。桌面宽屏下预览占工作行宽度约 55%，右侧设置区占剩余空间；1500×800（侧栏展开）窗口下预览区域约 626×399 像素。1100 像素以下窗口保留参数区最小宽度，自适应分配预览。默认桌面刷屏页无纵向滚动，发送、设置及播放按钮同时可见。

## 验证

- 同页布局源码版与发布版完整页面回归各 **184 项通过、0 失败**，覆盖共享会话、推荐值、自定义屏、初始化重放、刷图、视频/动图、局部刷新、寄存器/GRAM 读回与关闭连接。
- 1920×1080、1600×900、1500×800、1280×720、960×640 下，默认刷屏页无纵向溢出，包括选择自定义分辨率后，所有设置与播放按钮仍完整可见，参数区无内部滚动。600×800 的窄屏改为预览和参数上下排列，避免内部滚动区，保留整页自然滚动。
- 模拟探针 ST77916 整屏发送：529 帧、259208 字节、帧错误 0、页面未捕获异常 0。
- 使用离线模拟探针验证，未连接或操作实体屏和探针；不涉及传输协议及固件修改。

复测：`node tools/selftest/spi-panel-page.test.mjs`（本地页面 8899，测试浏览器 CDP 9333）；发布构建检查 `npm run check:web`。

## 屏页直接调整 SCLK

SCLK 频率选择、“应用”和实际频率读数位于左侧“屏配置”的“屏型号”卡片中，紧接“套用推荐值”下方；右侧刷屏布局保持原样。选项与桥页共用。应用时先读取当前配置，再只修改 `sclkHz`，回读对账并读取实际 SCLK；未使能时实际频率可能为“—”。套用推荐值或桥页修改频率会同步更新此处。刷图、播放等忙时禁止调整。

同时修正配置事件误填通信档位的问题：配置回读只更新 SCLK，档位事件才填写档位。新增模拟页面回归验证左侧位置、两页双向同步、忙时不写入、60 MHz 回读，以及模式、CS、引脚、DMA 阈值和通信档位保持不变。

新增 SCLK 后完整发布版页面回归 **190 项通过、0 失败**，构建一致性检查通过。
