# SPI/QSPI 屏刷屏区域布局修正

原“刷这一张”按钮位于预览右侧参数列底部。1500×800 窗口下被 `.imginfo` 的内部滚动区遮挡；1280×720 和 960×640 下还超出刷屏页可视范围，造成按钮像是消失。

修正后，刷屏页保留两组图案（纯色、图案）、选择图片/刷这一张操作栏和整块预览。文件入口不再单独占一行，支持将 BMP/PNG/JPEG 拖入预览区。图片参数、动画/视频分别使用独立页签；预览窗口与分片说明默认折叠。自定义宽高只在选择“自定义”时显示，套用内置屏推荐值时同步隐藏。压缩主区与日志之间的间距，保留日志高度拖动。

预览画布占满可用区域，按原图比例显示；移除旧的 380 像素宽度上限。1500×800 窗口下预览区域约 1137×390 像素。默认刷屏页无纵向滚动，发送按钮完整可见。

## 验证

- 源码版页面回归 183 项通过；最终发布版页面回归 **184 项通过、0 失败**，覆盖共享会话、推荐值、自定义屏、初始化重放、刷图、视频/动图、局部刷新、寄存器/GRAM 读回与关闭连接。
- 1920×1080、1600×900、1500×800、1280×720、960×640、600×800 下，默认刷屏页均无纵向溢出，发送按钮完整可见，预览占满区域。
- 模拟探针 ST77916 整屏发送：529 帧、259208 字节、帧错误 0、页面未捕获异常 0。
- 使用离线模拟探针验证，未连接或操作实体屏和探针；不涉及传输协议及固件修改。

复测：`node tools/selftest/spi-panel-page.test.mjs`（本地页面 8899，测试浏览器 CDP 9333）；发布构建检查 `npm run check:web`。
