# SPI→USB 并发回归

完整硬件对照、原始数据和探针修复说明位于 [探针仓库回归报告](https://github.com/minichao9901/5301evk_akaLinkPro/blob/main/docs/validation/2026-10-08-spi-cdc-regression.md)。

SPI 未启用时，RTT 转发约 2.9 MiB/s、单变量 JScope 约 496 kHz，与加入前接近。最终 `make full_flow_f103ze` 重跑通过主流程 20 项、调试压力 82 项；初次因 60 MHz 自动退档而失败的记录也保留。三变量极限速率最终两轮为 109.57 / 94.20 kHz，并非每次恒定；高采样率流程只断言跑通，不能当成零跳拍保证。

18 MHz SPI 同时输入约 2.25 MB/s 时，探针原搬运循环会追着 DMA 新到字节直到耗尽预算，严重挤占采样。修复后：单变量 2 µs 从 35.156 提升到 428.648 kHz；20 µs 恢复 50.000 kHz、八变量 100 µs 恢复 10.000 kHz，后两组稳定窗口跳拍为 0。高采样率仍有约 11–14% 探针跳拍。

Web 修复低实际速率下挂起原生读取未收干净、重新开始要求整设备复位而与 CDC 占用冲突的问题：按实测吞吐量有界排空；必要时只关闭独占的 WebUSB 句柄取消读取，然后重开。共享 WebUSB 使用者仍阻止独占收尾，没有取消占用保护。

四组并发稳定窗口的 SPI 缺帧/载荷错误/乱序/探针丢弃均为 0，HSS USB 丢样本/读错误/样本高位错误/计数回退/包乱序也为 0；初始化、标定仍有 SPI 覆盖丢弃，2/3 µs 停止阶段总计 USB 丢样本为 714 / 195。因此结果只保证记录的稳定窗口，不能表述成全程无损。ADC 使用真实硬件矩阵验证计数、位宽、速率、DMA 环回和连续采集；SPI 主机/屏、I²C 等使用假探针与真实 DOM 验证，不宣称外接器件实测。

CFI 单元测试另固定 ELF 快照在 `tools/selftest/fixtures/`，供用户下载的目标 ELF 继续由构建流程更新并随源码提交。这样不会因工具链改变指令地址，把夹具变动误判为局部变量回归。

最终 `make test-host`、`make test-offline` 通过，八类真实 DOM 页面检查通过；ADC 实机 317/0（61 次采集），CMSIS-DAP 在 1–60 MHz 八档读写 20 KiB 逐字节一致。目标全部 512 KiB Flash 已恢复并读回比对相同。所有原始记录、初次失败与最终产物哈希均保留在上述探针仓库报告旁的同名目录。
