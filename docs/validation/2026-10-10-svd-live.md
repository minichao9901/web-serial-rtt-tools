# SVD 运行刷新、变化高亮与 H743 / H750 预置

日期：2026-10-10。

## 行为

- 新增“运行中也刷新”，默认关闭，可保留用户选择。调试器的 SVD 面板可见时，约每 500 ms 读取当前选中的一个寄存器及其位域，不扫描整个外设。
- 与上一运行读取值相比发生变化时，寄存器值及变化的位域显示橙色。每个位域按最后变化时间独立计时，约 2 秒稳定后恢复；即使后续没有读取，计时器也会清除运行变化高亮。
- 暂停、单步或命中断点后，自动读取当前寄存器，与上一次暂停读取快照比较。运行中读取不会替换暂停基线，同一次暂停再次读取也不会立即抹掉变化。第一次暂停读取建立基线；下一次暂停值未变时恢复颜色。
- 当前 SVD 在另一个调试器 dock 页签隐藏时，暂停快照仍会更新；运行中自动采样只在 SVD 面板可见时进行。
- 后台读取使用已有 `tryExclusive()`，前台调试操作优先；模型、寄存器或目标连接改变后，不接纳旧读取结果。断开及换 SVD 时清除比较历史。
- 自动读取跳过只写及 SVD 标记有读取副作用的寄存器，读错时关闭运行刷新并显示原因。STM32 SVD 不用于 RISC-V 目标。SVD 未标注的硬件读取副作用不能自动推断，仍需选择匹配的目标和寄存器。

## 官方数据与首屏影响

新增 H743 / H750 来自 Arm Keil STM32H7xx_DFP 4.1.3，固定官方提交 `4c77d2ffa6e885b6da9d6fe949c2d6070b21fe7d`，保留 STMicroelectronics 版权和 Apache-2.0 头。来源及许可见 [内置 SVD 说明](../../app/dbg/svd/README.md)。

| 型号 | XML 版本 | 外设 | 寄存器 | 压缩加载体积 |
|---|---:|---:|---:|---:|
| F103 | 原有文件 | 53 | 722 | 32,696 B |
| H743 | 1.9 | 122 | 2946 | 195,801 B |
| H750 | 2.3 | 122 | 3067 | 236,478 B |

原解析器未展开外设 `derivedFrom`，H7 的 GPIOB、USART2 等 51 个外设会显示空寄存器列表；本次完成继承展开，保留实例自己的基址，并检测循环和缺失父外设。

原始 XML 与压缩副本同时保存；现代 Chrome / Edge 读取 `.svd.gz` 并解压，不支持时使用 XML。两份 H7 数据只在选择型号时下载，不进入首屏合并脚本。压缩源按 LF 规范化，避免不同系统换行导致副本校验失配。

## 验证

- Node：F103 / H743 / H750 解析、全部继承外设非空、GPIOB / USART2 / TIM2 地址、压缩副本、字段解码、继承循环拒绝均通过。
- 高亮状态：运行变化过期、各位独立过期、暂停基线不被运行读取替换、重复暂停读取、首次快照及清空状态均通过。
- 源码版和合并版真实浏览器页面各 **20 项通过**。使用模拟内存读数，验证了真实 DOM、调试观察循环、前台独占时跳拍、读错停用、错误架构不读取，以及 1600 / 1280 px 布局。
- 现有调试器独占队列测试通过；源码语法、合并脚本清单和 Markdown 格式检查通过。

本轮没有连接或控制实机；H743 / H750 的寄存器定义及界面已验证，具体板上的实时采样仍待实机回归。

发布后通过真实 GitHub Pages 合并入口再次加载两份预置 SVD：H743 为 122 / 2946，H750 为 122 / 3067，与本地一致；压缩传输量分别为 195,801 / 236,478 B，无页面异常。验证期间调试会话始终未连接硬件。结果见 [线上数据检查](2026-10-10-svd-online.json)。
