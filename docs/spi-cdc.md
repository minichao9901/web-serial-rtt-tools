# SPI→USB 使用与验收

新入口在「SPI/QSPI 屏」后面，原「SPI/QSPI 桥」入口改为「USB→SPI/QSPI」。新页用探针的 SPI **从机**接收外部主机字节，再经现有 CDC 串口输出。SPI 时钟由外部主机产生，默认 Mode 0 / MSB，支持四种 Mode 与 MSB/LSB。数据为 8 位原始流，不添加报文头或 CS 边界。

HPM5301EVKLite 复用 SPI2：PB10 CS（J3[26]）、PB11 SCK（J3[13]）、PB13 MOSI（J3[28]）；PB12 MISO（J3[27]）只接收可不接。与主机共地、3.3 V 电平、CS 低有效。

1. 连接探针，选择与外部主机相同的 SPI 模式及位顺序。
2. 打开下方探针 CDC 接收口，点击「启动转发」。也允许在转发已启动后打开串口，但之前未接收的数据可能丢弃。
3. 启动外部 SPI 主机。CDC 波特率不限制字节率。
4. 保存或记录数据。完整二进制记录关闭「记录带时间戳」；接收区仅保留有限历史，高流量自动停止显示，接收统计与已开始的文件记录继续。
5. 停止外部发送后点「停止」。转发停止不会关闭共用接收串口。未搬入 CDC 的尾部数据计入丢弃。

SPI 从机与 USB→SPI/QSPI、SPI/QSPI 屏、ADC 共用 SPI 引脚和缓冲，启动时统一仲裁。SPI 和 SWD 引脚独立，可同时 SWD 调试。CDC 的 UART、RTT、SPI 数据源互斥；与 RTT 并列提供页面，不会将两个无分帧流同时混入同一 COM 口。J-Scope 勾选暂停 CDC 时也须先释放转发资源。停止失败会保留占用提示，重连原功能并成功停止后才能切换。

固件采用主循环服务门控，HID 0x39 只排队 START/STOP，借用原 SPI 主机的 16 KiB 环做循环 RX DMA，再搬入原 32 KiB CDC 环；每轮最多 4096 B。响应 SPC1 能力字、pending、返回码和运行位用于确认完成，页面显示接收/转入 CDC/丢弃及 FIFO/DMA 错误计数。

## 实测与复现

2026-10-08，F103ZE SPI1 连到探针，CPU 72 MHz：4.5/9/18 MHz 对应主机实收约 **0.563/1.125/2.250 MB/s**，三档各 10 s 全量字节和序号检查通过。18 MHz 另连续测 20 s（45 MB）无错误；hello world 连续流每字节检查通过；9 MHz 四 Mode × 两种位顺序八组合全通过。

**真实新页面** 18 MHz 接收 10 s 为 **2.250098 MB/s**，全流序号及载荷无误，探针丢弃/FIFO/DMA 错误为 0，页面心跳最大间隔 35 ms。故意关闭接收口时丢弃计数增长、缓冲有界；重新打开、停止并重启后恢复完整接收。18 MHz 是当前最高验证档位，未宣称探针极限。

发送端例程与已编译 ELF：探针仓库 `script_test/stm32f103_spi_tx/`。完整协议与硬件原始数据：探针仓库 `docs/spi-cdc.md`、`docs/validation/2026-10-08-spi-cdc.md`。默认发送端上电 `g_run=0`，测试脚本经 SWD 切换 hello/校验帧和 SPI 时钟；测试结束关闭发送、转发及端口。

# 真硬件：发送端例程已烧录、浏览器已授权探针与 CDC

网页回归包括启动中断开、STOP 失败、晚到的 HID 连接、共用串口与源切换、SWD 共存；独立真页面模拟流共记录 4,915,200 B，逐字节一致。全部 13 页在 1600/1280 宽度布局检查 58 项通过。新页复用 RTT 接收组件，独立显示设置和清空操作，共用底层串口读取。
