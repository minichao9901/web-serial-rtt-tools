③ 固件计算与建议

时钟路径公式（F103 / H7）

F103 · ETMv3：SYSCLK = HSE ÷ PREDIV × PLLMUL（或 HSI 8 MHz）
CPU = HCLK = SYSCLK ÷ AHB 分频
Trace 输入 = HCLK；引脚 TRACECLK = HCLK ÷ 2（4 位 DDR，由引脚输出）

H7（PLL1 使用 HSE 时）· ETMv4：VCO = HSE ÷ M × (N + FRACN ÷ 8192)
CPU = VCO ÷ P ÷ CDCPRE；HCLK = CPU ÷ AHB 分频
TRACEPORTCK 由 RCC 选 HSI / CSI / HSE / PLL1_R；引脚 TRACECLK = TRACEPORTCK ÷ 2，PLL1 路径时 = VCO ÷ R ÷ 2

每半周期样点 = LA 采样率 ÷ (2 × 引脚 TRACECLK)
晶振等板级量只能人工填写，回读不到的频率不会用旧值冒充。

职责划分：固件负责 HSE、供电、Flash 延迟、PLL、总线/外设/SysTick、缓存/MPU 与业务引脚预配；网页负责 Trace 引脚（F103 为 PE2～PE6）、trace 门控/复用/路由、ETM/TPIU 配置与采集，停止或恢复时回写改过的寄存器，不覆盖其他 GPIO。

① ETM / TPIU 配置

选项说明与芯片能力

分支广播：额外输出直接分支地址，增加 Trace 带宽压力。默认关闭；关闭后依靠匹配 ELF 和分支结果重建执行流，不裁剪采集范围。F103 CDC 48/24 MHz 下，关闭后连续三轮 10 ms 无 overflow。

返回栈压缩：减少函数返回地址的输出，降低带宽；只在硬件支持时可选。

周期计数：增加周期信息和输出量。当前图表仍按执行序号展示，不能直接当作逐指令时间轴。

F103（ETMv3）：返回栈压缩和周期准确模式不支持，页面禁用并拒绝下发；Trace 引脚固定为已验收的 50 MHz 复用推挽。恢复时 TPIU 保持并行模式。H7B0（ETMv4）的选项以硬件能力回读为准。

录制与历史分析


操作顺序：载入匹配 ELF → 连接探针 → 添加并选择起点断点 → 核对时钟 → 联动采集 → 保存与解码。


在函数前点 ＋，或输入 b main.c:199 添加硬件断点。圆点选择采集起点；建议选初始化后的业务函数，例如 F103 例程的 trace_workload_round。采集期间本页断点暂时停用，结束后恢复。


默认“先复位，再运行至起点”：每次采集都会重新复位并停在所选断点。不勾选则运行到下一次命中该断点；若该位置只执行一次，应先复位。


Web 校验目标 Flash 与 ELF，停在起点后配置 ETM/TPIU，等待 Kingst 就绪，再继续 CPU。从起点恢复运行不等于每条起点指令都已解码；ETM 同步前与捕获尾部的边界明确保留。


固件负责：真实 HSE、PLL、CPU/HCLK、Flash 等待周期及业务外设。PE2～PE6 可预先配置，但运行中不能占用或覆盖它们。Web 联动模式的固件无需自行开启 ETM。


Web 负责：读取 RCC、计算频率、配置 Trace GPIO/ETM/TPIU/同步、复位/暂停/继续/硬件断点，以及 Kingst 采集、记录保存、解码和源码浏览。输入时钟字段不会改写 PLL。外部晶振频率需要用户按电路填写。


F103ZE 基线：HSE 8 MHz、CPU/HCLK 48 MHz、Trace 输入 48 MHz、引脚 TRACECLK 24 MHz。H7B0 基线为 CPU 70 MHz、TRACECLK 35 MHz，Trace 输入来自 PLL1_R。支持能力以识别和回读结果为准，F103CB 没有 ETM。


F103 的返回栈压缩和周期准确模式不支持，页面禁用并拒绝下发；GPIO 使用已验收 50 MHz 复用推挽。恢复 F103 设置时 TPIU 保持并行模式，切换 SWO 前应复位目标并重新配置。


ETM 常用选项在采集页可选并回读：分支广播增加地址输出和带宽压力，默认关闭；返回栈压缩减少返回地址输出；周期计数增加数据量。选项按芯片能力启用，不支持的选项会禁用并拒绝下发。F103 CDC 建议 CPU 48 MHz / TRACECLK 24 MHz，关闭分支广播；仅降频仍可能 overflow。实际寄存器配置随记录保存。
Kingst 基线：500 MSa/s、CH0～4 对应 PE2～PE6，共地，半周期取样位置 0.25。F103 当前实测门限 2.0 V；滤波在 KingstVIS 中设置，记录保存实际快照。


H743 阿波罗板：HSE 25 MHz，建议先用 CPU 60 MHz / TRACECLK 30 MHz、500 MSa/s、CH0～4=PE2～PE6、门限 1.65 V。超过 30 MHz 的物理 Trace 时钟需重新验证信号与解码质量；同 DEV_ID 的其他型号未验收。初始化起点选 trace_hook_entry；它位于时钟初始化之后、CDC 初始化之前。长记录自动使用磁盘分页，旧版超大结果需要重新解码。帧错误会明确报错，不能将字节核算或源码映射率当作无损证明。
右侧浏览保存的历史不会单步目标。灰色祖先、未知条件和失同步不补猜。Timeline/火焰图横轴为执行序号，不代表耗时；指令 Trace 不提供变量值或局部变量历史。
